# 素材库（产品通用轨）

这里存放产品通用轨（REQ、BIZ、SYS、DAT、GRO、STR、UXD、DLV、LCM）出题用的素材卡。完整规则见 `..\题库模板\碎片内容整合规则.md`，搜集方法见 `..\题库模板\知识搜集方案.md`。

## 目录

| 文件夹 | 放什么 |
|---|---|
| `_收件箱\` | 还没整理的碎片：文章摘录、课堂笔记、面试被问到的题、经历回忆，随手丢 |
| `_待核实\` | 来源不足或说法冲突、暂时不能用的卡 |
| `_旧题迁移\` | 从旧 306 题拆出来的 E 类卡 |
| `REQ\` `BIZ\` `SYS\` `DAT\` `GRO\` `STR\` `UXD\` `DLV\` `LCM\` | 已整理的卡，文件名 `<概念键>__<两位序号>.md`，例如 `REQ\req.user_story__01.md` |

## 五条速记

1. 一张卡只讲一个概念下的一个论点。
2. 每张卡都要写来源；没有来源的只能放 `_待核实\`。
3. 原文最多摘 2 句，其余用自己的话。
4. 经历类内容先脱敏：不写公司、客户、内部系统名称和未公开数字。
5. 导入题库后，把正式题号回写到卡片的 `used_in`。

## 卡片模板

```markdown
---
card_id: REQ-user_story-01
concept: req.user_story
source_type: A          # A 权威 / B 经验 / C 公开案例 / D JD面经 / E 旧题
source: 书名+章节 / URL / 项目名
credibility: 高         # 高 / 中 / 低
collected: YYYY-MM-DD
use_for: [F骨架]        # F骨架 / X论据 / 案例 / 例句 / 误区 / 高频考点
privacy: 无需           # 无需 / 已脱敏（写明做法）/ 待确认
used_in: []
---

## 论点（一句话）

## 原文摘录（最多 2 句，可省略）

## 要点（自己的话，3–5 条）

## 可用例子

## 易错点 / 常见误解

## 英文表达（可选）

## 补充
```
