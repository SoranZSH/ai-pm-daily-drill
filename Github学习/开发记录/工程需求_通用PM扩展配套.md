# 工程需求 · 通用 PM 领域扩展配套（2026-10-31）

> 交给工程方面的 Agent 处理。**结论先行**：新增产品通用轨（REQ、BIZ、SYS、DAT、GRO、STR、UXD、DLV、LCM）**不需要任何代码改动**即可导入和推送，已用沙盒验证（见文末）。下面是配套改进，按优先级排列；第 1 条是现有缺陷，其余是体验优化。
> 约束：保持两个程序松耦合；不改动 `当前题库\`、`题号登记.json`、`已导入\`；每项改动配测试，并保留现有测试全部通过。

## 1. 【P1 缺陷】采集程序给项目打概念标签时按子串误匹配

- **位置**：`Github学习\collector\library.py` 的 `_concept_hits`（约第 64 行）。
- **现状**：别名用 `a in low` 做纯子串匹配；而 `classify.py` 的 `_has` 对英文别名用了词边界。两处不一致。
- **已发生的误判**：别名「DPO」命中了单词 endpoint，`资料库\项目\TauricResearch__TradingAgents.md` 因此被标上 `trn.preference`（偏好对齐）。别名「ANN」同理会命中 channel、annotation 等词。
- **影响**：资料库「涉及的知识地图概念」一栏失真；采集包里「相关题」「尚未出题的前置概念」会出现无关概念。新增通用 PM 概念后，误判会更多。
- **要求**：
  1. `_concept_hits` 改为复用 `classify._has`（英文按词边界，中文按子串）。
  2. 写测试覆盖：DPO 不命中 endpoint，ANN 不命中 channel，`user story` 命中 user story，中文别名照常命中。
  3. 提供一次性回刷：用新规则重算 `资料库\index.json` 与各项目 `.md` 中的概念标签，并重新生成 `资料库\索引.md`。
- **验收**：`collector\tests` 全部通过；回刷后 TradingAgents 不再含 `trn.preference`。

## 2. 【P2】资料库索引与练习界面认识新领域名称

- `collector\library.py` 的 `DOMAIN_NAMES` 只有 AI 轨 10 个领域。新领域会显示成代码（如「REQ」）。补上：REQ 需求分析与管理、BIZ 业务架构与流程、SYS 信息系统与技术基础、DAT 数据分析与指标体系、GRO 增长与客户成功、STR 产品战略与商业模式、UXD 用户研究与产品设计、DLV 开发流程与团队协作、LCM 产品立项与生命周期。
- 更好的做法：改为从 `当前题库\*.json` 的 domain / category 动态读取，去掉写死的表（可选）。
- `ui\` 里的 `CAT_COLOR` 查不到分类时用默认紫色，功能正常；如需区分两轨，可按「AI 轨 / 通用轨」给两套主色（可选）。

## 3. 【P2】选题支持「学习重点」配比

- **背景**：两轨的题进入同一个选题池，按现有规则随机抽。面试冲刺期想集中练某几个领域时，目前做不到。
- **建议**：在 `题库路径.json` 增加可选配置，例如：
  ```json
  "focus": {"domains": ["REQ", "BIZ", "SYS"], "weight": 3}
  ```
  在 `ui\state.py` 的 `_pick` 中，候选池内属于 focus 领域的题按权重加大被抽中的概率。不配置时行为与现在完全一致；仍保证「同一天结果稳定」和「前置未练完不推拓展题」。
- 领域从题号前缀取（`REQ-F001` → REQ），旧格式题目不受影响。
- **验收**：新增单测覆盖「无配置时结果不变」「有配置时 focus 领域占比显著上升」。

## 4. 【P3】跨领域前置提醒合并显示

- `题库更新.exe` 对每一个跨领域前置单独提醒一条（`plan.go` 约第 316–323 行）。两轨互为前置后会很常见，一个领域可能出现十几条相同提醒，淹没真正的问题。
- **建议**：合并成一条汇总，例如「本次有 8 个跨领域前置：LLM-F002、PRM-F001…（可以，但请确认确实需要）」。仍算提醒，不算错误。
- 改完重新编译 `题库更新.exe`，`main_test.go`、`v21_test.go` 同步更新。

## 5. 【暂不做】采集程序扩展到业务系统类项目

- 通用产品知识以标准、教材、经验为主，按 GitHub 热度追新的收益很低；案例题需要的少数开源业务系统（工作流、工单、ERP 类）可以手工加入资料库。
- 如以后要做：只需在 `collector\方向词表.json` 增加方向（domain 写 SYS 或 BIZ），无需改代码；但要先完成第 1 条，否则误标会更严重。
